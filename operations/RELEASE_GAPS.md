# V1 发布前外部事项与未实现范围

以下项目不是占位功能，界面不表示其已经完成：

- 真实阿里云短信送达、余额和计费联调需要已实名账号、最小权限 RAM AccessKey、四类短信模板、方案名、计费资源及测试手机号。
- `SMS_DAILY_COST_WARNING_COUNT`、三类保留天数、服务器规格、域名、上线地区与预算必须由发布负责人确认；示例值不能自动视为业务批准值。
- 外部日志/告警平台尚未选型；应用已提供脱敏日志事件与受保护运维状态端点，生产通知路由需要部署时接入。
- 手机号旧号不可用时不提供自助绕过，必须按人工身份恢复流程处理。
- V1 不包含 M7 AI、历史版本恢复、任意 HTML/SVG/脚本上传、Word 导入导出、公开分享、支付或生产部署。
- 源码许可证和非商业条款仍待公开前确定。
